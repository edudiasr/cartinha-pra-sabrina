# Pra você, Sasa 💚

Cartinha de aniversário em site. Abre direto no celular, sem instalar nada.

## Como testar na hora

Abra o `index.html` no navegador, ou use a extensão **Live Server** no Cursor/VS Code.

No celular da mesma rede, o jeito mais fácil é subir no GitHub Pages.

## Subir no GitHub Pages

1. Crie um repositório (você já criou).
2. Envie estes arquivos para a raiz do repositório:
   - `index.html`
   - `css/`
   - `js/`
   - `assets/`
   - `.nojekyll`
3. No GitHub: **Settings → Pages → Branch: `main` → folder `/ (root)` → Save**.
4. O link fica assim: `https://SEU-USUARIO.github.io/NOME-DO-REPO/`

Não precisa de build, Node ou instalação.

## O que tem no site

- Entrada cinematográfica + confetes ao carregar
- Cartinha + foto
- Balão de coração pra tocar e revelar a memória
- Corações verdes interativos
- Cronômetro até **05/09/2026 às 23:00** (horário de Brasília)

O cronômetro usa a data real. Não depende de salvar nada no celular: enquanto a página estiver aberta, ele continua descendo sozinho.
